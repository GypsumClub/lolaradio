# Lola Radio

A broadcast station for someone who has passed. You write messages to them, and the station keeps them on air — looping, always playing — so the love keeps going out into the universe.

Designed by Xavier Armando. Built with Meta AI.

**Live demo (v1.9.3):** https://sparkly-palmier-af16a1.netlify.app/
**This repo:** source backup — currently **v1.9.4**, a single-file build in `index.html`.

## How it works

- **On air:** the current message plays on the station screen, with Pause / Next
- **Rotation:** messages stay in rotation for 30 days, then rest in the archive
- **Favorites:** keep the essential ones close
- **Themes:** Black, Cream, Malachite, Sakura, Ultramarine
- **Storage:** on-device only. No account, no server — "private and stays on your device" is the point

## Principles

- Never claim a message was delivered or received
- No fake replies, no guilt mechanics
- The core act — writing and broadcasting — stays free

## Roadmap

Data export → media messages (photos, audio) → multiple stations → brand identity → app-store version (Capacitor, so data lives in the app and backs up with the device).
